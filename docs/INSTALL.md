# Установка

Два независимых артефакта; вместе дают полный охват интерфейса.

| Артефакт | Что закрывает | Куда ставить |
|---|---|---|
| `TerrariaUI.tmod` (мод) | стеклянные панели, слоты, HUD, курсор, скрим, дизайн-лаборатория | `%USERPROFILE%\Documents\My Games\Terraria\tModLoader\Mods` |
| `Arima-UI Terraria.zip` (ресурспак) | меню, настройки, конфиги модов — все ванильные пластины и скроллбары | `%USERPROFILE%\Documents\My Games\Terraria\ResourcePacks` |

Порядок:

1. Скопировать `TerrariaUI.tmod` в папку `Mods`.
2. Скопировать `Arima-UI Terraria.zip` в `ResourcePacks` (не распаковывая).
3. Запустить tModLoader → Workshop → Mods → включить **Terraria UI** → Reload.
4. Главное меню → Workshop → Resource Packs → перенести пак вправо (Enabled).
5. Зайти в мир.

Ресурспак читается при загрузке игры, поэтому после его замены нужен перезапуск.
Мод перечитывается по Reload.

## Настройка

`Settings → Mod Config → Terraria UI`. Всё на русском и английском.

Полезное:

| Параметр | Зачем |
|---|---|
| `Плотность панели` | насколько плотное стекло; выше — меньше видно мир |
| `Яркость кромки` / `Сила блика` | «дороговизна» материала |
| `Затемнение фона` | скрим под интерфейсом; 0 — выключить |
| `Стеклянная полоса HUD` | заменить ванильные сердца своей полосой |
| `Панель — X/Y`, `Ширина/Высота панели` | подгонка под свою раскладку (другие моды сдвигают сетку) |
| `Дизайн-лаборатория` | показать все компоненты на одном экране |
| `Отладочный оверлей` | разрешение, масштаб UI, линейка |

## Если что-то не применилось

| Симптом | Причина |
|---|---|
| Меню светлое, как в ванили | пак не включён или лежит не в `ResourcePacks` |
| Скроллбары белые | в игре старый пак: заменить архив и перезапустить игру |
| Панель поверх слотов | сдвинуть `PanelX/Y` и `Ширину/Высоту` под свою сетку |
| Сердца остались ванильные | `Модули → HUD` выключен |
| Двойной HUD | включён сторонний HUD-мод: выключить либо его, либо `Стеклянную полосу HUD` |

## Удаление

Удалить `.tmod` из `Mods` и архив из `ResourcePacks`. Ничего в мире не сохраняется:
мод клиентский и не меняет данные игры.
